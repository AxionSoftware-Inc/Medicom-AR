# Medicom AR

Medicom AR is a lightweight web-based augmented-reality navigation project designed for indoor clinic navigation.

The project provides browser-based navigation from predefined points to rooms and destinations. It is deployed as a static web application and is intended to work through QR-linked access without requiring a separate mobile application.

## Project scope

- Indoor clinic navigation
- QR-based access
- Web-based AR/navigation experience
- Predefined routes, destinations, and distance data
- Lightweight static deployment through GitHub Pages
